Process

How I Build

01
Whiteboard First
Every project starts with a whiteboard and sticky notes — mapping data flows, user interactions, and edge cases before writing a single line of code.
02
AI as Co-Pilot
Use AI to accelerate execution — scaffolding, debugging, edge-case handling — while keeping creative direction and architecture human-owned.
03
Ship to GitHub Pages
Deploy early, iterate in public. No server infrastructure, no overhead — just a live URL and a commit history that tells the story.
04
Stream the Process
Take the audience along. Weekly Newscapes Live! shows document the build process — wins, failures, and everything in between.
